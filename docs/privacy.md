# Privacy Notes

Clinical trial data is not appropriate for public redistribution through a portfolio repository.

## Excluded

- raw data,
- cleaned data,
- participant IDs,
- row-level dates,
- derived row-level outputs,
- Excel issue trackers,
- protocol/SAP PDFs,
- generated reports containing private study content.

## Included

- parameterized R code,
- aggregate results,
- public-safe documentation,
- clinical/statistical interpretation.

This gives interviewers enough to evaluate the analysis design without exposing participant-level information.
