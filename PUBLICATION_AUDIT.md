# Publication Audit

This repository is a curated, no-data public portfolio version of the BIS 681 clinical analysis project.

## Published

- Polished README and public documentation.
- Parameterized R scripts showing analysis structure.
- Aggregate-only study and treatment-effect summaries.
- Privacy note explaining why data is omitted.

## Excluded

- Raw trial data.
- Cleaned trial data.
- Participant-level records.
- Participant IDs and row-level dates.
- Excel issue trackers.
- Protocol/SAP/intervention PDFs.
- Generated DOCX/PDF reports containing private study material.

## Rationale

Clinical trial data should not be redistributed through a public portfolio repo. This repository therefore demonstrates analysis design, code organization, and interpretation using aggregate results only.
